# Kennely 2027.12 – GitHub / VS Code / Netlify Free

Dieses ZIP ist das **vollständige Projekt**, nicht nur ein Teil-Patch.
Es übernimmt die Funktionen von Kennely 2027.10 und die Layoutkorrekturen
von 2027.11. Bestehende Turso-Daten sollen erhalten bleiben.

## 1. Vorbereitungen

1. Sicherung von **beiden** Turso-Datenbanken (MAIN und MEDIA) erstellen.
2. ZIP in einen **separaten** Ordner entpacken.
3. In VS Code dein bestehendes GitHub-Projekt `kennely-github` öffnen.
4. **Den Inhalt** des entpackten Projektordners in das Root-Verzeichnis des
   vorhandenen GitHub-Klons kopieren, bestehende Projektdateien ersetzen.
5. Den Ordner `.git` **nicht** löschen. Deine lokale `.dev.vars`, `.env` und
   gespeicherte Zugangsdaten **nicht** überschreiben oder hochladen.
6. Vor dem Commit Netlify-Environment-Variablen und die echte Domain
   `kennely.de` prüfen. `REGISTRATION_MODE` zunächst `closed` belassen.

## 2. Abhängigkeiten und Qualität prüfen

Im VS-Code-Terminal (PowerShell) **im Projektordner**:

```powershell
npm install
npm run policy:count
npm test
npm run check:js
```

`npm install` aktualisiert die beiliegende minimale `package-lock.json`
mit den vollständigen Paketinformationen. `npm run policy:count` muss
**mindestens 3000 verschiedene Filterbegriffe** ausgeben. Die Angabe ist erst
nach erfolgreicher Installation bestätigt. Falls zu wenige Begriffe geladen
werden: nicht öffentlich freischalten; npm-Installation und Abhängigkeit prüfen.

## 3. Bestehende Datenbanken sorgfältig erweitern

Erst **nach einem Backup** und nur mit deinen gültigen, lokal gespeicherten
Turso-Secrets:

```powershell
npm run db:check
npm run db:migrate
```

Die Migration ergänzt `profiles.comment_policy`, `profiles.discoverable` sowie
Indizes für Follower-, Kommentar- und Emoji-Abfragen. Sie verwendet vorhandene
Datenbanken, erzeugt keine zusätzliche neue Datenbank und überschreibt keine
existierenden Kontodaten. Die beiden Turso-Datenbanken werden nicht in einer
gemeinsamen, atomaren Transaktion geändert: Backup und Ergebnis prüfen.

## 4. An GitHub senden, Netlify deployen

```powershell
git status
git check-ignore -v .dev.vars
git ls-files .dev.vars
git add -A
git --no-pager diff --cached --name-only
git commit -m "Kennely 2027.12 – Interaktionen, Datenschutz, Team und Mobile"
git push origin main
```

**Warnung:** `git ls-files .dev.vars` darf **nichts** ausgeben. Vor dem
Commit die gestagten Dateinamen auf Geheimnisse wie `.env`, `.dev.vars`, Tokens,
API-Schlüssel und Passwortdateien prüfen. Das verbundene Netlify-Projekt
veröffentlicht den Push nach seinem erfolgreichen Build. Im Netlify-Dashboard
Deployment- und Functions-Logs prüfen.

## 5. Das wurde umgesetzt

- Eigenen Nutzer- und Anzeigenamen ändern, auch als Teammitglied: 30 bzw.
  sieben Tage serverseitige Wartezeit. Anzeigename ist freiwillig.
- Eigene Teamlabels, abgestufte rollen- und personenbezogene Rechte; blauer
  Verifizierungshaken wird nicht durch einen selbst erfundenen Label ersetzt.
- Kommentar-Dialog mit Antworten, Likes, Melden, Löschung und Bestätigungen.
  Lange gedrückt halten auf Touchgeräten bzw. ••• klicken am Desktop.
- Profil und Chat miteinander verknüpft; Nachrichten doppeltippen für ❤️,
  weitere Emoji-Reaktionen auswählbar.
- Volle Beitragsfotos mit eigener Ganzbildansicht; sichtbares + zum
  Fotoauswählen; große mobile Klickflächen; keine fremde Gastseite beim Refresh.
- Privates Konto, Folgelisten-Sichtbarkeit, Nachrichtenanfragen, Kommentarrechte
  und optionale Deaktivierung der normalen Profilsuche. Staff darf weiterhin
  nach Berechtigung Moderationsfunktionen ausüben.
- Geschlecht: Frau, Mann, Divers, Nichtbinär, Sonstiges und Keine Angabe.
- Mobile Menü-Scrollbar, teamtaugliche responsive Nutzerlisten, Audit mit
  Benutzername/Profilbild/Verifikation.
- Mehrsprachiger Textfilter mit externem Wortlistendatensatz; explizite
  Prüfung rassistischer Schimpfwörter. Moderation findet *vor* Veröffentlichung
  statt und berücksichtigt menschliche Prüfung; kein Anspruch auf alle Sprachen.

## 6. Vor dem öffentlichen Betrieb

Mit **zwei verschiedenen Accounts** auf Handy und PC prüfen: öffentliche und
private Beiträge, Follower-Anfragen, Kommentarlikes, Antworten, Meldungen,
Löschen, DM-Reaktionen, Staff-Override, Rechte, Audit, Freigabeschlangen und
Profilsuche. Auf iOS Safari und Android Chrome Zoom bei Texteingaben,
Scrollposition im mobilen Menü, Dateiauswahl und Bilder testen.

Die eingebauten automatisierten Tests decken API-Abläufe und Sicherheitsteile ab,
nicht Browser-Layout, echte Smartphone-Latenz, Netlify-Last oder alle
Rechtspflichten. Für Netlify Free besteht keine dauerhafte WebSocket-Verbindung;
ankommende Nachrichten werden im Intervall abgeholt. Erstmalige Downloads
benötigen weiter Zeit; ein garantiert sofortiger Bildaufbau ist technisch nicht
möglich. Das Design verhindert versehentlichen Fokuszoom durch ausreichend
große Textfelder, deaktiviert aus Barrierefreiheitsgründen aber nicht die
Browser-Vergrößerung insgesamt.

Bitte auch die echten Angaben in Impressum, Datenschutz, Altersprüfung,
Community-Regeln und Meldungs-/Einspruchsverfahren prüfen; Testgrün ist
keine Rechtsfreigabe.

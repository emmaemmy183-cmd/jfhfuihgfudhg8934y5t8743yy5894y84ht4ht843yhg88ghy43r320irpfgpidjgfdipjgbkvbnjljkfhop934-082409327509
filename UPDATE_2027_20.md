# Kennely 2027.20 – vollständiges Update für GitHub und Netlify Free

## Was geändert wurde

- **Profil-Navigation:** Öffnet andere Nutzerprofile innerhalb der Website ohne echten Seitenreload. Die URL wird für Browser-Zurück aktualisiert; beim Öffnen erscheint ein kleines Ladegerüst anstelle einer falschen Gast-/Startseite. Verspätete Feed-Antworten überschreiben kein inzwischen geöffnetes Profil mehr.
- **Beitrags-Likes:** Sofortige rote, gefüllte Herzen und hoch-/herunterzählende Zahlen. Erneutes Klicken entfernt den Like. Backend-Zustand wird abgeglichen; bei Netzwerkfehlern wird die lokale Änderung rückgängig gemacht.
- **Follows:** „Folgen“ → **„Entfolgen“** (weißer Button, dunkle Schrift), erneutes Klicken entfolgt. Die angezeigte Followerzahl ändert sich unmittelbar. Für private Konten heißt der Zustand **„Angefragt“**; ausstehende Anfragen erhöhen die Followerzahl **nicht**. Erneutes Klicken zieht die Anfrage zurück.
- **Follower/Gefolgt:** Eigenes, scrollbar begrenztes Fenster mit Profilbildern, Namen, Verifizierung und Profilnavigation. Die API berücksichtigt Privatsphäre und lädt höchstens 60 Benutzer pro Anfrage; bei Bedarf „Weitere anzeigen“.
- **Aktivitäten/Gespeichert:** Kleine Foto-Kacheln in einem 3-spaltigen Handy- und 4-spaltigen Desktop-Raster. Anklicken öffnet den vorhandenen Beitrags-Detaildialog. Die Seiten benutzen auf Desktop mehr Platz und lassen die leere Vorschlags-Seitenleiste weg.
- **Kommentare:** Der sichtbare Kommentarzähler steigt bei automatisch freigegebenen Kommentaren; nicht freigegebene Kommentare erhalten einen ausdrücklichen Wartehinweis. Diese Moderationsregel verhindert irreführende öffentliche Zahlen. Die bereits vorhandene Kommentar-Eingabe, Antworten, Likes und @Markierungen bleiben.
- **Story-Editor:** Text in der Vorschau mit Maus oder Finger ziehen (Pfeiltasten als Alternative), Bilder per Regler zwischen 100 und 200 Prozent zoomen, auf Touch-Geräten mit zwei Fingern hineinzoomen. Die Zoomstufe wird als sehr kleine Story-Stilangabe gespeichert. Story-Erwähnungen, Löschaktionen und Repost-Freigabe aus 2027.19 bleiben.
- **Touch-Bedienung:** Interaktive Elemente sind für schnelles Tippen optimiert, Eingabefelder werden auf mobilen Geräten nicht durch zu kleine Schrift automatisch hineingezoomt. **Die systemweite Browser-Zoomfunktion bleibt aus Barrierefreiheitsgründen nutzbar.**

Keine Reels, keine Videos. **Musik ist nicht eingebaut:** Ein durchsuchbarer Katalog oder die Wiedergabe kommerzieller Musik braucht einen rechtlich nutzbaren Musikdienst mit entsprechenden Lizenzen. Keine scheinbar funktionierende Musikfunktion ohne Ton/Lizenzen.

## Technische Grenzen

- **Sofortiges Feedback** gilt für Klicks auf dem eigenen Gerät. Netlify Free unterstützt in dieser Architektur keine dauerhaft offenen WebSocket-Verbindungen; Live-Aktualisierung anderer Personen in Sekunden ist nicht garantiert. Chats nutzen weiterhin sichtbarkeitsabhängige zeitversetzte Abfragen. Für globale Echtzeit ist ein zusätzlicher Realtime-Dienst nötig.
- Followerlisten werden seitenweise abgerufen, statt die ganze Tabelle auf einmal zu versenden. Der bestehende 650-KB-Bildergrenzwert und die serverseitige Autorisierung bleiben erhalten.
- Es wurden **keine neuen Tabellen oder Datenbankspalten für 2027.20** benötigt. Die Story-Zoominformation liegt in dem bestehenden JSON-Stilfeld aus 2027.19.
- Diese Änderungen sind kein Garant für fehlerfreie Bedienung auf jedem Browser oder bei großer Last. Smartphone-Safari und produktives Netlify müssen gesondert geprüft werden.

## Installation in den bestehenden GitHub-Ordner

1. Das ZIP entpacken. Den Inhalt in deinen bereits geklonten Ordner `kennely-github` kopieren und bisherige Projektdateien ersetzen. Den `.git`-Ordner, `.dev.vars` und `.env` **nicht** löschen oder mit archivierten Beispielwerten überschreiben.
2. PowerShell im Projektordner öffnen:

```powershell
npm install
npm test
npm run check:js
npm run policy:count
npm run db:check
```

3. **Nur wenn die Migration von 2027.19 bzw. älteren Versionen noch fehlt:** Beide Turso-Datenbanken sichern, Sicherungen prüfen, dann `npm run db:migrate` und `npm run db:schema` ausführen. Wenn 2027.19 vollständig migriert wurde, ist für 2027.20 keine Migration nötig.
4. Vor GitHub-Upload Geheimnisse prüfen:

```powershell
git status
git check-ignore -v .dev.vars
git ls-files .dev.vars
git add -A
git --no-pager diff --cached --name-only
git commit -m "Kennely 2027.20 Reaktionen und Profile"
git push origin main
```

`git ls-files .dev.vars` muss **leer** sein. Niemals private Tokens, `.env` oder `.dev.vars` committen. Netlify sollte nach Push auf den richtigen Branch neu deployen. Prüfe anschließend das Deployment-Log, die Versionsanzeige und Tests auf echten Geräten.

# Kennely 2027.15 – Korrektur für Großbuchstaben im Benutzernamen

## Problem

Im Dialog **Einstellungen → Benutzername / Anzeigename ändern** akzeptierte das HTML-Eingabefeld nur Kleinbuchstaben. Die Registrierung akzeptierte dagegen Groß- und Kleinbuchstaben. Deshalb löste `MahBnk0071` trotz gültiger Länge den Browserfehler „Please match the format requested“ aus.

## Änderung

- Beide Formulare verwenden jetzt denselben Ausdruck für die Eingabe: `[A-Za-z][A-Za-z0-9._]{9,23}`.
- Großbuchstaben dürfen eingegeben werden; der Server normalisiert den Benutzernamen weiterhin auf Kleinbuchstaben. `MahBnk0071` wird also als `mahbnk0071` gespeichert.
- Direkt unter dem Eingabefeld wird erklärt, welche Zeichen erlaubt sind.
- Einheitliche Formularkontrolle mit automatischem Regressionstest.
- Version und Cache-Busting des Frontend-Skripts auf 2027.15 erhöht.

**Keine neue Datenbankmigration erforderlich, wenn die Migrationen bis 2027.14 bereits korrekt ausgeführt wurden.** Sind ältere Migrationen noch offen, zuerst beide Turso-Datenbanken sichern und die Anleitung aus 2027.14 beachten.

## Installation

1. ZIP in einen separaten Ordner entpacken; nur seinen Inhalt in das GitHub-Projekt kopieren. **`.git` und vorhandene `.dev.vars`/`.env` nicht löschen oder überschreiben.**
2. Im VS-Code-Terminal des Projekts ausführen:

```powershell
npm install
npm test
npm run check:js
npm run policy:count
```

3. Bei erfolgreicher Prüfung und mindestens 3.000 Filtereinträgen prüfen, was versioniert wird:

```powershell
git check-ignore -v .dev.vars
git ls-files .dev.vars
git add -A
git --no-pager diff --cached --name-only
git commit -m "Kennely 2027.15 - Benutzername Grossbuchstaben fixen"
git push origin main
```

`git ls-files .dev.vars` darf keine Ausgabe liefern. Danach in Netlify das Deployment kontrollieren, `https://kennely.de/einstellungen` mit Strg+Umschalt+R neu laden und bei der Profilidentität `MahBnk0071` eingeben. **Der Benutzername wird serverseitig kleingeschrieben** und kann nur alle 30 Tage geändert werden.

Nicht nur Test-Syntax, sondern auch eine reale Nutzung mit mindestens zwei Konten und echten Turso-Datenbanken prüfen. Kein Update kann absolute Fehlerfreiheit oder vollständige Moderationsabdeckung garantieren.

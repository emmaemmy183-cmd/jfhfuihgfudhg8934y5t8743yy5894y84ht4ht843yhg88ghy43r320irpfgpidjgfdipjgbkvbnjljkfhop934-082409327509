# Kennely 2027.18 – Desktop-/Mobil-Neustrukturierung

Diese **vollständige Projektversion** baut auf Kennely 2027.17 auf. Die Funktionen für Kontosperren, Einspruch direkt auf der Sperrseite, Turso, Netlify, Moderation, Benutzer- und Anzeigenamen sowie private Profile bleiben erhalten.

## Neue Oberflächen

- **Profile:** Vollständig überarbeiteter Header, Profilfoto, Beitrags-/Followerzahlen, Bio, Bearbeiten- bzw. Folgen-/Nachrichtenaktionen und dreispaltiges Foto-Raster. Auf Desktop großzügig und auf Smartphones kompakt.
- **Beiträge:** Beim Öffnen eines Rasterbildes Desktop-Ansicht mit vollständigem Bild links und Kommentaren samt Eingabe rechts. Auf Smartphones eigene, scrollbare Foto-Detailansicht. Die Bilder werden nicht beschnitten.
- **Kommentare:** Mehrzeiliges, sichtbares Textfeld statt des zu schmalen Eingabefeldes. Emoji-Leiste, Antworten, Likes und Moderationsoptionen bleiben bestehen. Auf Smartphones ein unabhängig scrollbares Dialogfenster vom unteren Bildschirmrand.
- **Nachrichten:** Emoji-Reaktionen stehen **außerhalb unterhalb** der Nachrichtenblasen. Doppeltippen bzw. Doppelklicken auf dieselbe Nachricht setzt ein rotes Herz; erneutes Doppeltippen entfernt es. Andere Emojis sind über das Reaktionsmenü wählbar. Die Auswahl wird sofort angezeigt und durch die bestehende API bestätigt.
- **Chat auf Smartphones:** Geöffnete Chats verwenden den gesamten verfügbaren Bildschirm, sodass das Nachrichteneingabefeld nicht hinter der unteren Navigation verschwindet.
- **Einstellungen:** Auf Smartphones klar getrennte Abschnitte, auf Desktop geordnete Einstellungsbereiche. Alle bestehenden Datenschutzeinstellungen bleiben erhalten.
- **Weiterhin nur Fotos/Foto-Storys:** Keine Reels oder Video-Uploads.

## Update der bestehenden GitHub-/Netlify-Installation

1. Beide Turso-Datenbanken als Vorsichtsmaßnahme sichern. **Für 2027.18 sind keine neuen Datenbankschemaänderungen vorgesehen**, sofern die bisherigen Migrationen bereits vollständig ausgeführt sind.
2. Den ZIP-Inhalt in den bestehenden geklonten `kennely-github`-Projektordner kopieren, Dateien ersetzen. Den Ordner `.git` und lokale geheime Dateien `.dev.vars`, `.env` nicht überschreiben oder hochladen.
3. In PowerShell:

```powershell
npm install
npm test
npm run check:js
npm run policy:count
git check-ignore -v .dev.vars
git ls-files .dev.vars
git status
```

4. **Vor dem Push** prüfen, dass `git ls-files .dev.vars` nichts ausgibt und dass `npm test` / `npm run check:js` erfolgreich sind. Wenn `npm run policy:count` weniger als 3.000 Einträge meldet, ist der ursprüngliche Wunsch an den Wortfilter noch nicht erfüllt: nicht ignorieren.
5. Erst dann:

```powershell
git add -A
git --no-pager diff --cached --name-only
git commit -m "Kennely 2027.18 Responsive Profile Comments Chat"
git push origin main
```

6. Netlify Deployment-Status kontrollieren. Auf Mobilgerät und PC neu laden. Mit **zwei Konten** Fotobeiträge, Kommentieren, Follower/Privatsphäre, Chatreaktion setzen und wieder entfernen, Profilansichten, Moderation und Sperrseite testen.

## Validierung und Grenzen

- JavaScript-Prüfung und automatisierte Tests sind auf einer lokalen Testumgebung durchgeführt worden.
- Die geänderten Ansichten wurden mit Chromium/Playwright bei **1440 × 900** und **390 × 844** mit simulierten API-Daten geprüft. Dazu zählt die tatsächliche Position des Kommentartextfeldes, die Reaktion unterhalb der Nachricht und das zweimalige Umschalten der Herz-Reaktion.
- Produktionsdatenbank, echtes Netlify-Deployment und Safari auf einem physischen iPhone wurden **nicht** getestet. Daher keine Zusage vollständiger Fehlerfreiheit oder identischer Darstellung auf jedem Gerät.
- Mehrsprachige Wortfilterzählung und die konkreten Rechts-/Sicherheitsanforderungen müssen separat überprüft werden.

# Kennely 2027.10 – Update aus VS Code

## Vorher

1. Beide Turso-Datenbanken sichern. Den GitHub-Ordner (`kennely-github`) geöffnet lassen.
2. Alle Dateien aus diesem ZIP in das GitHub-Repository kopieren und vorhandene Dateien überschreiben. **`.git` und `.dev.vars` nicht überschreiben, nicht hochladen**.
3. Die neue Version verwendet zusätzlich das npm-Paket `naughty-words` (CC BY 4.0), dessen Wortliste erst durch **`npm install`** geladen wird. Der beigefügte minimale `package-lock.json` wird dabei neu erzeugt. Diesen vollständigen Lock nach erfolgreicher Installation mitcommitten.

## Befehle – exakt in dieser Reihenfolge

```powershell
npm install
npm run policy:count
npm test
npm run check:js
npm run db:check
npm run db:migrate
```

Falls `npm run policy:count` weniger als 3000 Begriffe meldet, **nicht veröffentlichen**: Installation und Netzwerkverbindung prüfen. Der Wortfilter nutzt die importierte Sammlung mit vielen Sprachen, deckt aber nicht ausnahmslos jede Sprache oder jede Schreibvariante ab. Er stellt verdächtige Texte zur Prüfung zurück; eine Wortübereinstimmung ist keine rechtliche Feststellung.

Danach, nach Prüfung des Dateiänderungsstands:

```powershell
git status
git check-ignore -v .dev.vars
git ls-files .dev.vars
git add -A
git --no-pager diff --cached --name-only
git commit -m "Kennely 2027.10 – Profile, Kommentare, Privatsphäre und Tempo"
git push origin main
```

`git ls-files .dev.vars` muss **leer** sein; das `git check-ignore` muss `.dev.vars` als ignoriert zeigen. Keine echten API-Tokens oder Passwörter zu GitHub hinzufügen. Netlify startet bei verbundenem `main`-Branch automatisch ein Deployment.

## Änderungen

- Foto-Auswahl ausschließlich über sichtbares **+**; echter Datei-Input bleibt für Browser/Screenreader vorhanden, aber unsichtbar.
- Selbständerung von Benutzername (30 Tage) und optionalem Anzeigenamen (7 Tage) serverseitig begrenzt, auch für Teamrollen.
- Eigene Mitarbeiterlabels innerhalb der Rollenberechtigungen, ohne offizielle Rollen als selbst erfundene Labels ausgeben zu können.
- Threads: Kommentar-Fenster, Antworten, Likes und Melden/Löschen mit Bestätigung; eigene Kommentare und Kommentare unter eigenen Beiträgen löschbar.
- Nachrichten mit Doppeltipp-Herz bzw. anderen Emojis, klickbares Chatprofil und Rücknavigation.
- Vertrauliche Follow-Liste, Datenschutzoptionen, Nachrichtenanfrage-Regeln, privates Konto.
- Mobile Scroll- und CSS-Überlauf-Fixes; große Beitragsbilder statt Beschnitt, Fullscreen-Ansicht; mittiges + in mobiler Navigation.
- Bevorzugte Ansicht nach Neuladen per URL; kein kurz sichtbarer Gastbildschirm während der Sessionprüfung.
- Audit-Einträge und konfigurierbare Team-Berechtigungen für autorisierte Rollen.
- Kleine neue Turso-Tabellen für Likes/Reaktionen sowie bereinigte Kontolöschung, keine zusätzlichen Bildduplikate.

## Grenzen

Automatische Tests belegen wichtige API-Abläufe. Ein echter visueller iPhone/Android-Test und ein Live-Test von SendPulse, Turso und Netlify stehen nach dem Deploy aus. Netlify Free benötigt Polling für fremde Chat-Nachrichten (keine WebSocket-Garantie), deshalb lässt sich eine vollständig latenzfreie Anzeige nicht garantieren. Bitte das Online-Deployment und die Geräteansichten prüfen, bevor du alle Nutzer freischaltest.
